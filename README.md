# MARS-X

MARS-X is a browser-based autonomy test bench built on real HiRISE terrain of Jezero crater, Mars.
Explore the 1 m/px terrain in 3D, plan routes for a rover or an astronaut on foot (Marswalk) with different slope and
energy limits, and bring your own navigation policy (Python Gymnasium SDK run files or a drag-and-drop ONNX model) to get a
scorecard against the A* baseline. It is a first-filter lab for planetary autonomy, not a flight-ready system.

Built for NASA Space Apps 2026, challenge "Interplanetary Survival Guide: Martian Map".

## Repository layout

```
apps/explorer/     Web app (Vite, React, three.js); deployed to Cloudflare Pages
packages/schemas/  JSON Schemas generated from the Python models + golden fixtures
python/            Data pipeline (DEM/ortho/layers) and intelligence modules (planner, RL, benchmark)
scripts/           Cross-platform Node helpers (data copy with size checks, dataset packing, deploy)
docs/              ADRs (docs/adr) and DevOps notes (docs/devops)
data/              raw/ and processed/ are generated and git-ignored
```

## Run it

Requirements: Node 24 (see `.nvmrc`), pnpm 10 (via corepack), uv, optionally [just](https://github.com/casey/just).

```
just setup     # or: pnpm run setup
just data      # build data/processed/jezero-v1 from public USGS data
just test
just build
```

Dev server: `pnpm --filter ./apps/explorer dev` (port 5173). Deployment details: `docs/devops/deploy.md`.
