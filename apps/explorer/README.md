# MARS-X Explorer

Vite 8 + React 19 + TypeScript (strict) + Tailwind 4 + shadcn/ui + three 0.187 / React Three Fiber 9. Static SPA, no backend.

```
pnpm --filter @marsx/explorer dev          # http://localhost:5173 (serves ../../data/processed/jezero-v1 at /data/jezero-v1)
pnpm --filter @marsx/explorer test         # Vitest
pnpm --filter @marsx/explorer typecheck && pnpm --filter @marsx/explorer lint
pnpm --filter @marsx/explorer build        # prebuild writes the synthetic dataset if missing
pnpm --filter @marsx/explorer shots        # Playwright screenshots (1440 / 390, dark / light) into .shots/
```

`?data=<name>` loads `/data/<name>/manifest.json` (simple names only). Without it the app tries `jezero-v1`, then `synthetic`
(generated by `scripts/make-synthetic-dataset.mjs`, same format as the real pipeline output, labelled as not real Mars data).

## Layout

| Path | What |
|---|---|
| `src/core/data` | zod manifest validator (mirrors `packages/schemas/manifest.schema.json`), dataset loader with per-stage progress |
| `src/core/terrain` | `Heightfield` (CPU `sampleHeight`, `normalAt`, world/pixel/lon-lat), chunk mesh builder (runs in `terrain.worker.ts`), ortho tile pyramid |
| `src/core/rover` | `PathFollower` (waypoints + speed), `roverPose` (yaw from route, pitch/roll from terrain normal) |
| `src/core/mission` | planning-grid geometry, terrain ray casting for clicks, path statistics, plan-layer loading |
| `src/scene` | R3F scene: chunk manager (LOD + skirts), terrain material (`onBeforeCompile`), sky, sun, cameras, rover, mission layer |
| `src/store` | zustand stores: `app` (mode, layer, sun, haze, telemetry), `camera`, `rover`, `mission` |
| `src/ui` | shell: mode rail, topbar, inspector (desktop card / mobile sheet), telemetry bar, loading and error screens |

Coordinates: three.js world is x = east, y = up, z = SOUTH (z = -northing). Pixel rows grow south. Heights are metres on the DEM datum.

## Public APIs (for the conditions engine and other slices)

- `setSun(azimuthDeg, elevationDeg)` and `setHaze(tau)` in `src/store/app.ts`.
- `useRover.getState().followPath(waypoints, speedMps, loop)` and `.stop()` (waypoints in world metres).
- `useCamera.getState().setMode('orbit' | 'fpv' | 'chase')`; per-frame state in `cameraRig`.
- Layers: `terrainUniforms.uLayer` (0 none, 1 slope, 2 hazard, 3 CRISM; 2 and 3 reserved) and `uLayerOpacity`.
- `window.__marsx = { ready, fps, frameCount, chunks, triangles, mode, drawCalls, renderedTriangles, geometries, textures }` for Playwright.

## Notes

- The orthoimage is one monochrome HiRISE RED band, shown through a false-colour tint (declared in the UI).
- No StrictMode: R3F, workers and GPU resources are created once per mount. The terrain worker receives a copy of the elevation raster.
- FPS in headless runs is SwiftShader (software); measure frame time on a real GPU.
